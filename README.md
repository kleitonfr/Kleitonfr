**Stack:** NestJS · TypeScript · Prisma · MySQL · JWT · Passport · bcrypt · Jest

🔗 [Ver projeto](https://github.com/kleitonfr/nest-florestal)

---

### 🔐 LGPD360

Portal institucional desenvolvido para apoiar a **implementação e comunicação das ações relacionadas à LGPD** no município de Caraguatatuba.

O projeto reúne informações, orientações e conteúdos relacionados à governança de dados e privacidade no ambiente institucional.

🔗 [Acessar portal](https://lgpd360.caraguatatuba.sp.gov.br/)
